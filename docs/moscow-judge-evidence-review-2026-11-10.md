# Московские районные суды: проверка судей и судебной практики — 10.11.2026

Документ редакционного контроля; исходные сведения из официальных публикаций,
не статистика действующего судейского состава.

## Подтверждённое фактическое наполнение

- 35 районных судов Москвы имеют самостоятельные карточки и по восемь
  практических подразделов.
- В текущем каталоге **424 уникальные записи «суд + ФИО»**, если учитывать
  исторические официальные списки, публичные сообщения о назначениях,
  сведения о председателях и имена из справочников помощников судей.
  Это **не численность судей, работающих на сегодня**.
- Для 27 судов имеются опубликованные подборки списков судей. Для остальных
  восьми есть только ограниченные по составу источники:
  Замоскворецкий, Кузьминский, Мещанский, Тверской, Тушинский,
  Хамовнический, Чертановский и Щербинский районные суды.
- На сайте опубликованные имена из разных типов источников различаются:
  список судей / конкретное назначение / страница председателя /
  упоминание судьи в справочнике помощников. У каждой записи показан
  официальный источник и дата изучения.
- В каталоге `/courts/moscow/judges` появился полный перечень всех 35 судов
  с количеством индивидуальных записей в нашей подборке и прямыми
  внутренними переходами в судейские и судебные разделы.
- В восьми судах без полного списка страница `info/judges` показывает
  все подтверждённые отдельные кадровые публикации, вместо сообщения,
  будто сведения о судьях полностью отсутствуют.
- Раздел `info/cases` каждого из 35 судов умеет показывать источниковые
  записи с номером, судьёй и результатом **только по реестру**. Тексты
  судебных решений и итог апелляции этим не удостоверяются.

## Проверка текста судебных решений

- `moscow-judge-reviewed-decisions.json` пока содержит **0**
  утверждённых текстов мотивировочных судебных актов.
- `moscow-court-judgment-review-queue.json` содержит
  **6 отдельных карточек**, требующих анализа текстов и статуса
  публикации. Ссылка «Скачать файл» на официальной странице
  не равна прочитанному документу.
- Реестровая запись может свидетельствовать о вынесении акта
  либо о категории дела, но не позволяет выводить применённую норму,
  мотивировку, правовую позицию судьи или результат апелляции.
- Нельзя импортировать тексты, отмеченные «публикация запрещена»,
  или документы с ограничениями по данным сторон.
- Персональный каталог не рассчитывает процент отмен, условную
  «успешность» сторон или прогноз судебного решения.
- Исходные приватные JSON с возможными данными участников дел
  не добавлялись в GitHub.

Публикационные ограничения должны оцениваться по применимой редакции
Федерального закона № 262-ФЗ, в частности ст. 15, и правилам
обезличивания; одного указания автора в реестре недостаточно.

## Результат разработки и оставшиеся ограничения

Этот этап улучшает **отображение уже подтверждённых сведений**.
Он не утверждает, что все 35 судов имеют полный актуальный
состав либо что на сайте опубликован полный архив судебных решений.

Следующим уровнем редакционной готовности станет получение доступных
полных официальных решений и их юридическая проверка с подтверждением
авторства, номера/УИД, норм, ограничений и обжалования.
Где исходный файл недоступен, не подменять документ реконструкцией.

Код, проверки и данные — в GitHub. Coolify Deploy не выполнялся
и остаётся ручным действием владельца только после успешного
GitHub Actions на последнем коммите.
