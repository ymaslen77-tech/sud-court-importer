# Поиск судов по видам, регионам и адресу — этап 14.10.2026

## Внесённые изменения

- На `/` и `/courts` выводится функциональная форма выбора **вида суда** из 15 категорий и **региона** из доступных исследовательских записей; название/код суда необязательны.
- На `/courts/types` пользователь также выбирает категорию из выпадающего списка вместо сетки карточек. Справочные категории доступны ниже отдельными ссылками.
- Страница `/search?kind=general-district&region=region-54` учитывает оба фильтра. Подтверждённые записи из API всегда выводятся отдельно от предварительных; клиентские данные 151 исследовательской карточки не переводятся в `verified`.
- Создана страница `/jurisdiction` с выбором региона, категории дела, назначения адреса (истец/заявитель, ответчик, объект недвижимости, другое) и строкой адреса.
- Адресный подбор реализован **локально в браузере**: не записывается в URL, не передаётся на сервер и не сохраняется. ФИО и номера квартир не требуются. Значение адреса сравнивается только с известными населёнными пунктами и названиями судебных органов, и результаты помечены «суды для проверки», а не «официально установленная территориальная подсудность».
- Страница `/jurisdiction` имеет `noindex` до появления достоверных данных о границах, а адресный подбор не добавляет ссылок в sitemap.

## Ограничения

1. Сейчас исследовательские данные доступны по **Новосибирской области (36), Омской области (40) и Хабаровскому краю (75)**. Для других регионов данных индивидуальных карточек пока нет; полный список судебных органов в России нельзя имитировать.
2. Совпадение города в адресе заявителя и адресе суда **не доказывает подсудность дела**. Для точности до улицы и номера дома необходимо заносить юридически проверенные сведения о территориальных границах районных судов и судебных участков мировых судей и учитывать возможные изменения границ.
3. По общему правилу гражданский иск предъявляется по месту жительства **ответчика** (ст. 28 ГПК РФ), но существуют альтернативная, исключительная и другие подсудности; некоторые дела могут быть предъявлены по адресу истца (например, определённые потребительские требования, ст. 29 ГПК РФ). Подбор адреса заявителя сам по себе не может дать юридически точного ответа.
4. Не используются несанкционированные геокодеры, массовый краулинг, координаты без проверки или клиентский сбор пользовательских адресов.
5. Для полного определения подсудности в будущем потребуются: проверенные территориальные правила по каждому суду/участку, актуальная редакция статей процессуальных кодексов, правильное соотнесение вида дела и уровня суда, отслеживание изменений границ и отдельные тесты на пограничные адреса.

## Проверка

- `/courts`: есть `select[name=kind]`, `select[name=region]`.
- `/courts/types`: есть такие же поля; исторические карточки выбора заменены выпадающими списками.
- `/search?kind=general-district&region=region-54`: содержит Барабинский районный суд в непроверенной группе.
- `/search?kind=general-magistrate&region=region-27`: содержит судебный участок `27MS0001` в непроверенной группе.
- `/jurisdiction`: поле ввода адреса, выбор роли и вида дела, `noindex`; проверка адреса `Новосибирская область, г. Барабинск` предлагает одноимённый районный суд только для самостоятельной проверки подсудности.
