# Снимки страниц судов → предметные сигналы → очередь редактора

Статус реализации: локальный/offline intake. Этот механизм **не является**
непрерывным скачиванием со всех сайтов судов и не публикует изменения.

## Путь данных

1. Ответственный сотрудник проверяет действующие условия использования и
   допустимость получения конкретной страницы. Сохраняет исходные HTML-снимки
   официальной страницы контактов суда без модификаций в `data/import/`
   (в Git их не добавлять).
2. У соответствующего **уже проверенного** суда регистрируется разрешённое
   наблюдение с URL типа `https://mos-gorsud.ru/rs/<slug>/help/hours` и
   областью `contacts` или `hours` через `watch.py register`.
3. Первый HTML-файл фиксируется в `court_contact_snapshots` без публичных
   изменений. Следующий по времени снимок из того же `watch_id`
   автоматически сравнивается по телефону и e-mail.
4. `court_contact_change_events` сохраняет события
   `newly_observed` и `not_observed_in_new_snapshot` вместе с
   источником, временем, контекстом и ссылкой на два снимка.
   Исчезновение контакта из страницы **не доказывает его отмену**.
5. Новые сигналы видны в `/editor` (тип `contact_deltas`).
   Рассмотрение/игнорирование фиксирует редактора и время, но не меняет
   `courts`, `judges`, `judicial_appointments` и публичные контакты.
6. Точные изменения отдельного поля в опубликованной карточке требуют
   нового `profile.py propose` и затем независимого
   `profile.py approve` после проверки актуальности и прав.

## Команды

Все примеры с ID ниже должны быть заменены настоящим ID соответствующего
суда/наблюдения. Флаги attest подтверждают **уже выполненную** проверку;
не применяйте их к неподтверждённым файлам.

```powershell
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/watch.py register --court-id 1 --url https://mos-gorsud.ru/rs/lefortovskij/help/hours --scope contacts --reviewer "Ответственный редактор" --attest-permission
```

Сохраните оба официальных снимка в `data/import/hours-old.html` и
`data/import/hours-new.html`. Затем:

```powershell
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/official_contact_stage.py stage /input/hours-old.html --watch-id 1 --source-url https://mos-gorsud.ru/rs/lefortovskij/help/hours --captured-on 2026-10-14 --reviewer "Ответственный редактор" --attest-authorized-source
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/official_contact_stage.py stage /input/hours-new.html --watch-id 1 --source-url https://mos-gorsud.ru/rs/lefortovskij/help/hours --captured-on 2026-10-14 --reviewer "Ответственный редактор" --attest-authorized-source
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/official_contact_stage.py pending
```

Даты в примерах демонстрационные — указывайте фактическую дату
сохранения HTML, не старше 30 дней. Источник должен совпадать с уже
зарегистрированной разрешённой страницей.

## Защита от ложных сообщений

- Отсутствие всех видимых номеров и e-mail → снимок отклоняется,
  чтобы экран ошибки/заглушка не вызвал «исчезновение» всего справочника.
- Снимки разных `watch_id` или разные URL не сравниваются.
- Более старый снимок нельзя выдавать за новое состояние источника.
- Повторное получение неизменённого HTML не создаёт дубликаты.
- Простая смена формата телефона `8` ↔ `+7` не считается изменением.
- Данные проходят через закрытую очередь, а readiness блокируется,
  пока остаются необработанные сигналы.
- Фоновое скачивание HTML и 24/7 сервер не включены этим изменением.
- Тестовые наблюдения не равны законно полученным актуальным сведениям.

## Проверка в CI

Добавлен сквозной тест: исходные сохранённые HTML-снимки → PostgreSQL
→ обнаружение 3 синтетических сигналов → повторный stage без дублей →
защищённый редакционный POST → аудит решения → отсутствие изменений
публичных телефонов и судебных назначений.

Критерий по полноте справочника по-прежнему **НЕ выполнен**:
разрешённые текущие выгрузки всех типов судов и регионов РФ, реальные
адреса и телефоны, лицензированные фотографии, production-хост,
пользовательский IdP/MFA, мониторинг SLA и юридическая проверка
использования источников требуют отдельных доказательств.
