## Готовые инструменты

```bash
# 1. Безопасно скачать официальный PDF одним запросом (размер ограничен 250 МБ):
python importer/jurisdiction_pdf_acquire.py 5400202610010007 original-149-oz.pdf

# 2. Получить SHA-256 фактического PDF, список страниц-кандидатов приложений
#    и сведения о полноте текстового слоя (не OCR):
python importer/jurisdiction_pdf_inventory.py original-149-oz.pdf --expected-annexes 138 --output inventory.json

# 3. После отдельной проверки координат и их исходной СК:
python importer/jurisdiction_coordinates_csv.py reviewed-coordinates.csv staged.geojson --crs EPSG:4326
python importer/jurisdiction_geometry.py inspect reviewed-manifest.json staged.geojson
python importer/jurisdiction_geometry.py stage reviewed-manifest.json staged.geojson --confirm
python importer/jurisdiction_geometry.py audit --region 54
```

Скрипт загрузки принимает лишь официальный HTTPS-домен, не переходит на посторонние домены, проверяет начало PDF и считает реальный SHA-256. PDF-инвентаризация не признаёт обнаруженные по тексту заголовки подлинными без визуальной проверки страницы и не делает OCR автоматически.

**Важное ограничение:** `jurisdiction_geometry.py` принимает только EPSG:4326. Если первичные приложения используют МСК/Гаусса-Крюгера или другую систему, понадобится документированное преобразование по подтверждённым параметрам, прежде чем вызывать геоимпорт. Нельзя выдавать исходные X/Y в метрах за широту/долготу.

## Что потребуется для снятия блокировки

1. Получить оригинальный PDF по официальной ссылке из браузера с доступом к порталу. При необходимости документ может быть предоставлен как загрузка файла в рабочую среду; важно сохранить адрес и дату получения. Если файл превышает 250 МБ, обработать отдельные приложения, но только с учётом происхождения каждого фрагмента.
2. Сверить PDF-хеш и визуально номера всех приложений, карты, исходную систему координат, действительность закона и распределение участков.
3. Извлечь таблицы координат без догадок, проверить полигоны, полноту, перекрытия и пограничные адреса. Поместить лишь проверенные исследовательские геометрии в Neon.
4. Отдельно проверить территориальную и родовую подсудность, после чего создать механизм юридически утверждённых версий. Операция утверждения **не входит** в текущую загрузку.
