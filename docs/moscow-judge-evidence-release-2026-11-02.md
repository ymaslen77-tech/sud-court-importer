# Москва: судебные дела, судьи и двухуровневая проверка — партия 2 ноября 2026

## Принцип ускоренной юридической приёмки

**Не требуется отдельный блокирующий ручной аудит каждой бесспорной справочной записи.** Источники проверяются по типу утверждения, а не одним универсальным маркером «юридически проверено».

1. **Факты кадрового назначения**: имя, суд, указ, дата — при подтверждении на официальной кадровой странице или в опубликованном указе допустимы в справочник с точным источником и датой, без утверждения о текущей службе. Если два источника разнятся, запись помечается как спорная; по альтернативным ФИО нельзя автоматически объединять дела.
2. **Регистрационные факты дела**: суд, номер, УИД, судья, категория, результат — сверять по карточке дела; если есть второй официальный реестр той же судебной системы (например, апелляции), автоматически принимать совпадающие поля после проверки идентификаторов. Это два **отдельных реестра**, а не независимые публикации. Поля, которые подтверждаются только одним реестром, так и описывать.
3. **Юридические выводы**: какие именно нормы применены, почему суд пришёл к выводу, отменён ли акт — только по самому официально опубликованному документу; при необходимости отдельно проверять текст закона и апелляционное определение. Подтверждение номера, исхода и текста «Скачать файл» недостаточно для объяснения мотивов.
4. **Расхождения**: противоречие номера, УИД, судьи, категории, даты или исхода блокирует автоматическое объединение. Приоритет официальной карточке именно соответствующего производства, затем опубликованному тексту судебного акта. Сторонние каталоги — источники для поиска, но не замены официальной публикации.
5. **Исключения**: непубликованные документы, запрет публикации, особенности семейных и других дел с персональными сведениями. Не копировать ненужные персональные данные участников и тексты с ограничениями.

Их формат/условия использования, в том числе вложенные массивы, необходимо проверить на реальном файле до автоматического массового обновления; дубли УИД между стадиями не должны превращаться в дубли судебных решений.
