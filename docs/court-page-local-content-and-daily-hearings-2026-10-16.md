# Карточка суда: локальное содержание, Яндекс Карты и заседания за текущую дату

Дата: 16.10.2026. Реализация: ветка `feat/002-court-content-hearings-yandex`.

## Правило отображения

Преимущество имеют самостоятельные фактические разделы на нашем портале: адрес, телефоны, функции подразделений, часы приёма, местоположение, инструкция подачи, особенности электронной подписи, базовые ставки госпошлины, компетенция, история источников. Ссылки на государственные сайты оставлены для верификации фактов, перехода в личный кабинет, актуального банковского счёта и открытия конкретной карточки дела.

На всех десяти пилотных карточках присутствуют общие правила подачи по приказу Судебного департамента от 29.07.2026 № 222, информация о личном кабинете ГАС «Правосудие», примерный перечень документов, классификация процессуальной подписи, справочная таблица ставок по ст. 333.19 НК РФ. **Это общие правовые сведения**, а не выдуманный персональный регламент конкретного суда. Индивидуальные реквизиты для перевода денег не публикуются без актуальной проверки. У Барабинского и Омского судов сохранены дополнительные досье по зданиям, отделам и руководству, причём полномочия и обновления помечены как исследовательские.

Источники общей процедуры:
- https://www.garant.ru/products/ipo/prime/doc/414666621/
- https://www.consultant.ru/document/cons_doc_LAW_28165/1cfcdcc5936cbfc3ea52f964201a1bb6002be313/

## Заседания только на сегодня

Модуль `apps/web/app/lib/official-hearings.ts` строит `H_date=ДД.ММ.ГГГГ` по `Asia/Omsk` или `Asia/Novosibirsk`. Запрашивается **лишь одна** персональная официальная страница, через `/modules.php?name=sud_delo&srv_num=1`, без обхода других страниц или архивов, с timeout 6,5 с и повторным использованием ответа до одного часа (Next.js fetch revalidation). Точный заголовок списка должен соответствовать запрошенной дате, иначе даже извлечённые строки не показываются. Отображаются номер дела, время, зал и имя судьи, но не участники и не тексты обвинений. Ссылки на отдельные дела проходят ограничение на тот же официальный домен и тип страницы. При недоступности, ошибке парсера и несовпадении даты показывается «сегодняшнее расписание временно недоступно», никогда старый список. Нет CAPTCHA-обхода и агрессивного повторного сбора.

**Подтверждённое ограничение:** 16.10.2026 два независимых запроса с GitHub Actions к `oblsud--oms.sudrf.ru` и `barabinsky--nsk.sudrf.ru` с явно выбранной сегодняшней датой **завершились тайм-аутом** (отчёт GitHub: `Official hearing connection probe`). Это означает, что **текущая регулярная доставка записей не доказана**; успешная установка модуля не означает заполненность реальными заседаниями. Для гарантированной работы необходим разрешённый машинный канал официальной публикации или согласованный поставщик API. Не использовать недостоверные кешированные списки за август 2026 под видом октября 2026.

## Яндекс Карты

Используется встраиваемый iframe-виджет Яндекс Карт без JS API ключа и без вызова Геокодера. Для четырёх зданий доступны предварительные адресные координаты из открытых справочников (Омский областной, Новосибирский областной, Барабинский районный, Пятый апелляционный); они помечены как требующие сверки входа. Для остальных шести используется интерактивный поиск по опубликованному названию и адресу, без фиктивных точных координат. Ссылки «Маршрут» открывают Яндекс Карты. Чтобы гарантировать точную точку для всех, следует получить официально подтверждённые геокоординаты или вставляемые ссылки «Поделиться → Виджет карты» для каждой из десяти организаций.

Документация Яндекс: https://yandex.ru/dev/maps/mapstools/ и https://yandex.ru/support/maps/ru/concept/get-map-reference.

## Готовность выпуска

Перед публикацией обязателен CI на точном SHA, тест полноты локального содержимого и Яндекс iframe, проверка SEO/noindex и отдельная проверка реального HTTP на Vercel. Ожидаемое исключение: при недоступности `sudrf.ru` расписание показывает честный отказ, а не фиктивные значения. Массовая автоматическая загрузка судебных дел **не активирована**. Отдельная подзадача — узаконенный и технически доступный канал расписаний.
