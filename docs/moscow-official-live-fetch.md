# Разрешённое получение московского JSON — отдельный, выключенный по умолчанию шаг

**Статус 14 октября 2026 года: код защищённого загрузчика реализован, но фактический канал НЕ активирован.**

Подтверждено наличие категории «Контакты и часы приёма» на https://data.mos-gorsud.ru/opendata . Однако на момент проверки не удалось независимо подтвердить точную действующую ссылку на полный JSON этого набора, актуальную схему и допустимость регулярной автоматической загрузки по https://data.mos-gorsud.ru/terms-of-use .

Исторические данные за 2021 год не являются подтверждением состояния реестра в 2026 году.

## Контракт

`importer/official_moscow_fetch.py` не имеет фонового расписания, не включён в `court-intake` и не запускается сайтом/редактором. Он работает **только после отдельного явного запуска** и требует:

- точный официальный URL карточки набора `https://data.mos-gorsud.ru/opendata/...`;
- отдельный подтверждённый оператором URL JSON на HTTPS-хосте `data.mos-gorsud.ru`;
- ручную проверку текста условий, документированное основание для автоматического обращения и повторного использования;
- имя редактора и дату проверки (не старше семи дней);
- оба флага `automatic_access_confirmed=true`, `reuse_rights_confirmed=true`.

Проверка **не является юридическим заключением**. Вписывание галочек без действительного основания недопустимо. Прямой запрос не должен выполняться, пока лицензия, экспорт и их условия не подтверждены.

## Формат файла конфигурации

Создаётся **локально, после действительной ручной проверки**, вне Git:

```json
{
  "dataset_url": "https://data.mos-gorsud.ru/opendata/REAL_CONFIRMED_DATASET_ID",
  "export_url": "https://data.mos-gorsud.ru/REAL_CONFIRMED_JSON_PATH",
  "terms_url": "https://data.mos-gorsud.ru/terms-of-use",
  "reviewed_on": "YYYY-MM-DD",
  "reviewer": "Ответственный оператор",
  "permission_basis": "Фактическая цитата или реквизиты подтверждённых условий, разрешающих автоматическое получение и использование",
  "automatic_access_confirmed": true,
  "reuse_rights_confirmed": true
}
```

**Все ссылки и даты выше — заполнители, не реальные проверенные параметры.** Если источник требует специального разрешения, регистрации, токена или запрещает прямые запросы, не обходить это настройками программы.

## Команды

Сначала создать `data/import/normalized` как отдельный writable-каталог. `/input` внутри контейнера остаётся read-only.

Проверка конфигурации **без обращения к сети**:

```powershell
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/official_moscow_fetch.py check --settings /input/moscow-source-config.json
```

Разовое получение после действительного разрешения:

```powershell
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/official_moscow_fetch.py fetch --settings /input/moscow-source-config.json --output-dir /output
```

Запрос возможен только по HTTPS точного официального домена: без HTTP, внешних доменов, пользовательских учётных данных в URL, прокси, переадресаций и произвольных портов. Максимальный размер — 5 МБ, тайм-аут 15 секунд. Файл должен содержать ожидаемый UTF-8 JSON; превышение лимита и неожиданные ответы отклоняются.

Исходный JSON записывается под уникальным именем и вместе с `*.evidence.json` сохраняет адрес источника, SHA-256, момент загрузки и **самоутверждение оператора** о правах. Этот файл не удостоверяет свежесть содержания или юридическую корректность сведений о судах.

**Следующие шаги:** `moscow_raw_export.py inspect` → подтверждение фактических ключей JSON → `normalize` → проверка `moscow_sync.py validate` → закрытый staging → независимая редакционная публикация через `cli.py approve` при наличии прав.

## Проверки безопасности

- Никаких автоматических загрузок по расписанию до отдельной эксплуатационной приёмки.
- Никаких обращений к пользовательским сайтам, localhost, внутренним IP или произвольным доменам.
- Перенаправления блокируются, сертификат TLS проверяется стандартным доверенным хранилищем.
- Вторая загрузка с теми же именем файла и контрольной суммой не перезаписывает существующий файл.
- Невалидная конфигурация не вызывает сетевого запроса.
- Полученный JSON не изменяет `courts`, `judges` и `judicial_appointments`.
- Фотографии и судебные акты проходят отдельную правовую и фактическую проверку.

**Незакрытый критерий:** получить официальную действующую ссылку, документально подтвердить допустимый режим обращения и реально скачать допустимый файл. До этого система не считается подключённой к живому источнику.
