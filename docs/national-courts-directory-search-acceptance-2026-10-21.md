# Каталог судов России — приёмка поиска /courts (21.10.2026)

## Фактический охват

Поиск на главной странице `/courts` и странице `/search` объединяет **284 записи из существующих источников**:
- **151** предварительная региональная запись — Новосибирская область (36), Омская область (40), Хабаровский край (75 мировых участков), из них **10** имеют расширенные публичные справочные карточки с отдельными доказательствами; они НЕ тождественны верифицированному реестру API/Neon;
- **12** отдельных исследовательских карточек районных судов Москвы;
- **121** название арбитражных судов и присутствий из двух сохранённых наборов официальных перечней. Они имеют ссылку на раздел справочника с выбранным названием, но пока не персональную карточку.
Поиск **не означает**, что в РФ существует всего 284 суда. Данных по большей части субъектов нет.

В выборе региона есть 89 наименований из справочника РФ, включая территории, чей статус оспаривается на международном уровне. Значение в селекторе само по себе не означает действующую судебную организацию, территориальную компетенцию или наличие проверенных записей. Незаполненные регионы сгруппированы отдельно.

## Реализовано

- Один общий быстрый поиск на `/courts`: название, классификационный код, известный адрес здания, тип суда, регион. Поиск устойчив к регистру, различию ё/е и распространённой форме слова с другой последней буквой.
- Фильтрация по нескольким измерениям одновременно (AND); 15 видов суда; 89 регионов; сброс и быстрые сценарии; 20 записей на страницу; кнопки навигации; счётчик результатов и доступные URL-фильтры через `/search?...`.
- Московские 12 карточек входят в поиск; 151 предварительная региональная запись открывается на своих существующих URL. Десять публичных справочных карточек имеют отдельную отметку.
- Арбитражные названия доступны в одном поиске, но переход ведёт в `/courts/arbitration?q=<название>` для нахождения конкретного ряда, пока нет индивидуальной страницы и редакционной проверки.
- Для пустого региона/вида — понятное отсутствие данных и ссылка на официальный поиск вместо предположения об отсутствии суда.
- Верифицированный API/Neon сохранён **отдельным** блоком на `/search` и не смешан с непроверенными справочными данными. Исправлена прежняя ошибка, когда при поиске с видом суда проверялась только первая страница категории API.
- Клавиатура/aria-live, фокус, адаптивная сетка, ограничения длины строки, семантические подписи.
- Никаких невалидных территориальных сопоставлений: адрес здания суда НЕ является ответом по подсудности участника спора.

## Автоматическая приёмка

`apps/web/tests/national-courts-directory.test.cjs` исполняет TypeScript-фильтр и объединение реальных JSON: 284 записи, 89 субъектов в селекторе, отсутствие дубликатов, Москва, код ГАС, мировые судьи, арбитражные категории, строгая фильтрация региона, пустой результат, пагинация.

`importer/tests/test_national_court_directory.py` проверяет размещённые исходники и неизменность непроверенного статуса исходных записей. В GitHub Actions дополнительно выполняются tsc, Next.js build и HTTP smoke запросы на `/courts`, `/search` и `/courts/arbitration?q=...`.

## Что ещё необходимо для полной базы России

1. По каждому субъекту законным способом получить актуальную публикацию официального федерального и регионального судебного перечня и список мировых участков. Проверить разрешённость автоматизированного получения, версии и источники; не обходить ограничения.
2. Привести записи к справочнику уникальных судов, исключить переименования/ликвидированные и дубль по коду + первоисточнику; добавить даты редакционной проверки.
3. После каждого региона верифицировать индивидуальные карточки по официальному URL и перевести в отдельный подтверждённый реестр. Только тогда раздел «Опубликованные карточки» сможет отражать всю страну.
4. Для массового объёма тысяч карточек перевести фронтенд с локальных 284 записей на постраничный индекс PostgreSQL, обеспечив серверный поиск по морфологии и быстрые индексы. **Текущий клиентский фильтр рассчитан на имеющийся ограниченный набор**, а не на полный всероссийский массив.
5. Полная подсудность по дому, состав судей, реквизиты и расписания — отдельные самостоятельные проверки каждого суда и услуг, они не могут выводиться по названию региона.

## Условия выпуска
Изменения не затрагивают таблицы Neon, существующие 10 подтверждённые справочные страницы или новые 12 московских карточек. Публикация только после всех проверок CI, затем контроль статуса Vercel READY и основного домена. Статус наполнения всей России **остаётся частичным**, несмотря на готовность интерфейса поиска.
