# Суды Москвы — персональные карточки судей, дела и решения
Дата редакционной сверки: 31.10.2026.

## Реализовано

- Полный реестр **36 судов**, из них **35 районных**.
- Официально опубликованные ФИО **335 судей/упомянутых в судебных разделах лиц** из **26 районных судов**: 20 ранее разобранных составов, 3 отдельных сообщения/справочника, 3 новых списка Лефортовского, Басманного и Пресненского судов (34 человека).
- **13 конкретных записей о делах**, для каждой одновременно подтверждены суд, судья и номер в официальном перечне; **10 результатов из списка дел** и **3 записи без подтверждённого исхода**. **0 подтверждённых полных мотивировочных текстов** в новой подборке.
- Каталог: `/courts/moscow/judges`. Поиск по суду и имени, фильтрация категории и наличия опубликованного результата. Персональные страницы: `/courts/moscow/judges/[courtSlug]/[judgeSlug]`.
- Сохранены уникальные канонические URL основных карточек суда. Не создаются фиктивные «решения судьи», рейтинги и проценты исходов из выборки.
- На странице каждого судьи показывается точный источник ФИО, дата официального обновления (если опубликована), статус подтверждения, судебные категории и только проверенные привязки дела.
- Для Басманного и Пресненского судов в персональные карточки передано предупреждение об отдельных временных помещениях судей.
- Новые персональные страницы остаются `noindex` до отдельного анализа полноты и юридической корректности.

## Что пока не завершено

В ещё 9 районных судах Москвы нет локально проверенного полного списка судей: Бабушкинский, Гагаринский, Замоскворецкий, Кузьминский, Мещанский, Никулинский, Таганский, Хамовнический, Щербинский.

Из 26 судов со сведениями о судьях только 23 имеют локальные списки; по Тверскому, Тушинскому и Чертановскому имеются отдельные кадровые сообщения или упоминания, **не** полный проверенный состав.

Для всех остальных судей, по которым ещё не привязаны документы, персональная карточка прямо сообщает об отсутствии записей в нашей **неполной подборке**, а не об отсутствии судебной практики.

Не установлены: исчерпывающее количество дел по каждому судье, полный корпус опубликованных судебных актов, действующий кадровый статус всех судей, статистика по исходам с надёжным знаменателем, пересмотр/отмена конкретного решения в вышестоящей инстанции и полнотекстовая мотивировка конкретных актов. Эти поля **не могут** автоматически считаться подтверждёнными.

## Источники и порядок доверия

1. **Официальные персональные списки:** `https://mos-gorsud.ru/rs/<officialSlug>/structure/judges`, кадровые сообщения соответствующего суда, указы Президента РФ.
2. **Официальные судебные дела:** `https://mos-gorsud.ru/search` и персональные разделы `/rs/<officialSlug>/services/cases/`. Проверять суд, номер, год, ФИО/инициалы судьи в той же строке, категорию и статус рассмотрения. Строка списка сама по себе не гарантирует опубликованный текст судебного акта.
3. **Массовый первоисточник для дальнейшего импорта:** `https://data.mos-gorsud.ru/`. Официальный портал открытых данных содержит десятки машиночитаемых наборов, в том числе по делам первой инстанции и обжалованиям. Перед использованием проверять условия лицензирования и структуру полей; большие архивы **ещё не импортированы**.
4. **Вторичный исследовательский источник:** `https://sudact.ru/`, сторонние юридические каталоги и обзоры. Используются для обнаружения возможного документа и поиска аналога, но не как единственное основание для указания судьи, результата или правовой позиции. При расхождении приоритет официальной карточке и официальному тексту акта.

## Схема достоверности каждого дела

Минимальные поля: `courtSlug`, `judgeName`, `number`, `proceeding`, `topicId`, `category`, `status`, `outcome`, `decisionDate`, `sourceUrl`, `observedOn`, `judgeAttribution`, `judicialActTextVerified`.

Статусы раздельные:

- `pending`: по реестру известно о деле, **решение не подтверждено**;
- `outcome_recorded`: в реестре одновременно указан судья и опубликованный результат, **мотивировка/текст акта не проверены**;
- `judicialActTextVerified=true`: в будущем только после индивидуальной проверки полного официально опубликованного текста, дат, типа акта, сторон и ограничений на публикацию; в текущем файле таких записей нет.

Категорию `criminal-materials` нельзя объединять с итоговыми уголовными приговорами. Удовлетворённое ходатайство об обыске, аресте имущества или продлении меры пресечения не является выводом о виновности.

Если официальный список показывает лишь инициалы, соотнесение с полным ФИО допускается только при **однозначном совпадении в соответствующем суде**; при коллизии ФИО запись отправляется на дополнительную проверку. Не объединять однофамильцев из разных судов.

## Проверка качества и безопасное расширение

1. Собрать официальные списки судей оставшихся 9 судов и сверить назначения/временные помещения.
2. Изучить структуру выгрузок портала открытых данных, условия повторного использования и проверить поля `номер + суд + судья + категория + процесс + акт + дата + ссылка`.
3. Формировать нормализованную промежуточную таблицу; исключать дубли по суду и номеру/УИД с учётом инстанции, не смешивать судебные акты и записи о движении дела.
4. Для каждого найденного полного текста привязать URL документа и его статус публикации. Проверить применимость ст. 15 Федерального закона № 262-ФЗ, исключить из собственных аннотаций ненужные персональные данные участников.
5. Исследовать, какие конкретные правовые нормы и мотивы применены в опубликованном акте, только по тексту и с точной ссылкой. Не выводить «обычную позицию судьи» из нескольких дел и не создавать прогнозы исхода.
6. Если получена информация об апелляции, связывать решение первой инстанции с результатом пересмотра по номеру/УИД, не выдавая неподтверждённую «отмену» за факт.
7. Повторить автоматические тесты и CI; после проверки в production рассмотреть SEO для персональных страниц отдельно от страниц районных судов.

## Релиз

Ветка `infra/coolify-russian-vps`, приложение `sudy-web`. Публикация на `https://sud-russia.ru` осуществляется через Coolify после успешного CI. Изменения в GitHub **не равны** подтверждённому развертыванию на VPS. Ни одна новая страница судьи не открывается для поисковой индексации автоматически.
