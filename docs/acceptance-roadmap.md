# Проверяемый план завершения
Статус на 13.10.2026. Успешный CI не означает готовность публичной базы.

| Этап | Приёмочный критерий | Статус |
|---|---|---|
| 1. Аудит | Бэкап, миграции, тест восстановления | Частично: бэкап-сценарий есть, restore ещё не проверен на Windows |
| 2. Источники | Подтверждены URL, схема и условия машиночитаемых реестров | Частично: доступен ручной экспорт, полный автофид не подтверждён |
| 3. Все суды РФ | Полный реестр по регионам, проверенные опубликованные карточки | Не готово: 174 исходные строки, ноль новых verified-карточек |
| 4. Судьи | Подтверждённые ФИО, должности, даты, контакты | Частично: модель и очередь проверки |
| 5. Автообновление | Постоянный разрешённый ingest, семантический diff, оповещения | Частично: монитор и файловый intake, без live-host |
| 6. Фото/карты | Подлинные лицензированные фото и подтверждённые координаты | Код готов; данных нет |
| 7. Судебная практика | Официальные акты с надёжной связью с судьёй и судом | Не готово |
| 8. SEO | Индексация качественных уникальных карточек и проверка выдачи | Частично: шаблон и sitemap, нет наполнения |
| 9. Приёмка | Функциональные, security, a11y и backup-restore тесты | Частично: unit/build/Docker CI |
| 10. Запуск | TLS, постоянный сервер, резервирование, эксплуатационный runbook | Не готово |

Запрещённые ошибки: публичный вывод staging без проверки; вывод о закрытии суда по неполному снимку; утверждение кадрового назначения по совпадению ФИО; публикация фотографий без прав; создание координат по догадке.

Основные измеряемые показатели: проверенные публичные суды, уникальные коды в staging, покрытие по официальному эталону, изменения на проверке, ошибки источников, подтверждённые фотографии и геоточки.

Команда доступного отчёта: `docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/coverage.py`.

Состояние внешних блокеров документируется. До подтверждения источников и действительного веб-развёртывания нельзя объявлять проект полностью завершённым.
