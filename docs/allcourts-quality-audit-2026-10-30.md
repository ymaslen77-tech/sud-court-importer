# ВсеСуды: контроль качества перед импортом
30 октября 2026 года. Вендор выбран; полный набор данных пока не предоставлен.

## Проверено
- https://www.allcourts.ru/ заявляет 10 447 судов и участков в 89 регионах, 7 836 мировых участков, дата снимка 17.06.2026.
- Сумма 8 федеральных округов — 10 414, на 33 записи меньше общего итога. Не считать эти 33 дублями без объяснения провайдера.
- Сайт демонстрирует федеральные, региональные, районные, мировые, военные и арбитражные суды. Полнота и число записей по каждой категории не доказаны.
- Контрольная независимая сверка кодов: 00VS0000 (Верховный Суд РФ), 03OS0000 (Верховный Суд Башкортостана), 04OS0000 (Верховный Суд Бурятии). Данные есть в делах на официальных vsrf.ru и sudrf.ru.
- ВНИМАНИЕ: первые две цифры официального ГАС-кода могут не совпадать с кодом региона в приложении: Башкортостан — код региона 02, судебный код 03OS0000; Бурятия — регион 03, судебный код 04OS0000. Сопоставлять по документированному источнику, а не по префиксу.
- LawLabs подтверждает HTTP API с ключом и документацией по запросу. Контакт: info@allcourts.ru. Публичное разрешение на массовый экспорт и независимую публикацию ещё не получено.

## Запрос вендору
Полная JSON/CSV выгрузка или официальный постраничный API; тестовый пакет 100–200 записей; расшифровка полей, дата каждой записи, официальный идентификатор и сайт, статус реорганизации/закрытия, список категорий и регионов, условия коммерческого повторного использования, атрибуция, стоимость и обновления, объяснение 33 записей. Черновик запроса подготовлен в Gmail, НЕ отправлен.

## Офлайн-аудит полного массива
Скрипт: importer/allcourts_dataset_audit.py

    python importer/allcourts_dataset_audit.py --file /secure/courts.csv --mapping /secure/fields.json --official /secure/official-reviewed.json --as-of 2026-10-30

Файл полей поставщика задаётся явно (его настоящая схема нам пока не известна). Пример структуры конфигурации, НЕ фактическая схема API:

    {
      "fields": {
        "name": "title",
        "region_code": "region",
        "kind": "court_type",
        "official_code": "code",
        "observed_on": "snapshot_date",
        "official_url": "official_website",
        "status": "lifecycle"
      },
      "court_type_map": {
        "regional": "general-regional",
        "district": "general-district",
        "magistrate": "general-magistrate"
      }
    }

Независимый официальный список в --official: JSON-массив из official_code, name, region_code, status. Отсутствующая в выборочном эталоне запись НЕ считается несуществующей.

Проверки: повтор кодов, вероятные совпадения названий, отсутствие официального URL и кода, неизвестные виды, закрытый/объединённый/переименованный статус, наблюдение старше 180 дней, покрытие 89 регионов, несоответствия официальному перечню. Коллизии не сливаются автоматически. Содержание выгрузки не публикуется.

Код НЕ подключается к сети, НЕ подключается к БД, НЕ ставит verified=true и НЕ меняет работающий сайт.
