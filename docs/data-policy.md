# Политика данных и публикации

1. Первичные источники — официальные сайты судов и государственные публикации. Условия использования каждого источника проверяются отдельно.
2. Ни одна карточка суда не становится публичной без подтверждения источника, даты проверки и статуса verified.
3. Назначение судьи моделируется отдельной записью с периодом действия; председатель суда и председательствующий по делу — разные роли.
4. Изменения сохраняются в журнале, непрозрачные исправления запрещены.
5. Персональные данные судебных актов требуют проверки ограничений на публикацию и обезличивание. Не импортировать частные сведения сверх законных оснований.
6. Подсудность по адресу нельзя угадывать географической близостью. Нужны юридически проверенные территориальные границы и вид производства.
7. При недоступности данных показывается ошибка или пустое состояние, но не вымышленные факты.
