# Проверяемые назначения судей и изменение полномочий

## Структура

Из официального источника сохраняется предложение на рассмотрение: court_id, при необходимости известный judge_id, полное ФИО, должность, официальный URL и подтверждённая дата начала полномочий (может отсутствовать). Дата Указа Президента не всегда совпадает с датой фактического начала полномочий.

- `db/migrations/006_judge_appointment_review.sql`: таблица кандидатов без публичной публикации; SHA-256 предотвращает дубликаты идентичного предложения.
- `importer/judges.py nominate`: добавляет кандидата из официальной страницы. Не создаёт лицо и назначение.
- `importer/judges.py approve`: требует подтверждения действительности источника и ручного сопоставления личности. Если такое ФИО уже существует, автоматическое создание ещё одной персоны блокируется: нужно указать существующий judge_id и отдельно проверить тождественность.
- `importer/judges.py close`: по официальному источнику и известной дате закрывает активное назначение, сохраняя его как часть истории.
- `judicial_appointments`: публично используются только назначения со сверенным source.checked_at и ещё не истекшим сроком. Отдельные изменения пишутся в change_events.

## Пример команд в Docker (после публикации и проверки суда)

    docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/judges.py nominate --court-id 1 --full-name "ПРОВЕРЕННОЕ ФИО" --position "судья" --source-url https://mos-gorsud.ru/rs/lefortovskij/structure/judges --observer "Имя редактора"

После получения candidate_id и независимой проверки актуального назначения:

    docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/judges.py approve --candidate-id 1 --reviewer "Имя редактора" --attest-current --attest-identity

Эти команды — **шаблоны**, а не утверждение, что судья с данным примерным ФИО существует. Даты назначений, ссылки на акты и идентичность необходимо проверить вручную.

## Изменения

Если изменился HTML официального раздела «Судьи», монитор фиксирует изменение хеша и создаёт запись для проверки. Это ещё не доказывает, что конкретный судья переведён или освобождён от должности. При прекращении полномочий редактор устанавливает подтверждённую дату через `close` и сохраняет ссылку на официальный источник.

## Что не автоматизировано

- OCR, извлечение имён и должностей из страниц с произвольной разметкой.
- Самостоятельная юридическая оценка указов о назначении и прекращении полномочий.
- Объединение лиц с одинаковыми ФИО без отдельной идентификации.
- Сбор судебных актов и связь с судьёй без достоверного person ID.

Ни одна из перечисленных функций не должна автоматически объявляться выполненной до появления проверенных источников, тестов и редакционного протокола.
