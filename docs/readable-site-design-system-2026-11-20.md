# Дизайн-система удобочитаемого сайта «Суды России» — 20.11.2026

## Зачем выполнено изменение

Предыдущий `globals.css` (80+ KB) содержал десятки локальных размеров 9–13 px для ссылок, подписей, вопросов и карточек. Шесть основных пунктов навигации, контактная информация и справочные пояснения были оформлены слишком мелко. При этом новейшие судебные сведения и источники нельзя терять при редизайне.

Вместо переписывания всех страниц (с риском повредить работающие юридические формы) добавлен **отдельный единый слой `apps/web/app/readability.css`**, подключённый после прежних стилей в `layout.tsx`. Он меняет только типографику, композицию и адаптивность; API, SEO-метаданные, JSON, поисковые и редакционные алгоритмы неизменны.

## Типографика и ритм

| Компонент | Размер/правило |
|---|---|
| Основной текст | 17 px, line-height 1.72 на обычных экранах; 16 px на ширине ≤580 px |
| Длинные абзацы | максимально около 78 символов по ширине, без принудительного урезания контента |
| H1 | адаптивный, до 56 px, 1.14 межстрочный интервал |
| H2 | адаптивный, ориентир 26–36 px |
| H3 | ориентир 21–24 px |
| Ссылки и подписи источников | минимум 14–15 px в целевых справочных блоках |
| Интерактивные поля | минимум 16 px, доступный обводкой `:focus-visible` фокус |
| Навигация | 14+ px, минимальная высота 44 px |
| Цвета | тёмный текст, умеренно контрастная бордовая ссылка, светлый фон и границы |
| Мобильная адаптация | карточки и факты переходят в одну колонку, горизонтальное меню можно прокручивать |

Правила не применяют масштабирование менее 100% и не препятствуют браузерному зуму 200–400%. Печать юридических документов не менялась. Изображения не генерировались, сторонние шрифтовые файлы не добавлены; используется уже выбранная Manrope и системный резервный шрифт.

## Навигация по информации

- Добавлена ссылка для клавиатуры **«Перейти к основному содержанию»**, видимая при фокусе.
- На телефоне основное меню открывается через нативный пункт **«Разделы сайта»**, вместо скрытых за горизонтальной прокруткой ссылок. Раскрывается клавиатурой и не требует JavaScript.
- Указатели содержания (`court-toc`) стали сеткой полноразмерных ссылок, вместо плотной строки мелкого текста.
- Карточки показывают заголовок отчётливее, адрес и режим — вторичным текстом, а источники — читаемыми примечаниями.
- Страница `/courts/moscow`: **35 районных судов** сохранены без изменения списков, но разделены на алфавитные диапазоны «А — К», «Л — Р», «С — Я». Быстрые ссылки ведут непосредственно к нужной группе. На широком экране — две колонки, на телефоне — одна.
- Таблицы сохраняют горизонтальную прокрутку там, где много данных; статусы и сведения не сокращаются автоматически.
- Формы, судебные вопросы, раскрывающиеся FAQ, районные карточки, данные о судьях и результатах апелляций используют единый базовый размер текста.
- Сохранены отдельные крупные подписи и размеры текста в устаревших блоках Конституционного суда и юридических анкет: длинные пояснения теперь не тонут среди 12-пиксельного текста.

## Безопасность данных

- Официальные URL, ФИО, УИД и даты источников **не менялись**.
- `robots`, `noindex`, `sitemap` и правовая приёмка (#62) не изменены.
- Нельзя считать хороший дизайн подтверждением полноты судейских списков, действительности полномочий или содержания полного судебного акта.

## Проверки

`node --test apps/web/tests/readability-design-system.test.cjs` — проверяет подключение стилевого слоя, размеры, клавиатурный skip-link, 35 неповторяющихся судов в трёх алфавитных группах, сохранение ссылок на официальные источники и SEO-защиты. Запускается также в общем и московском GitHub CI.

`pnpm check`, `pnpm build` и существующие интеграционные тесты обязательны; успешная сборка не заменяет просмотр на настоящих экранах.

### Ручная визуальная приёмка после развёртывания

Проверить в браузере ширины **360, 390, 768, 1024 и 1440 px** на следующих страницах:

- `/` — главная, шапка, поиск, карточки и нижний блок.
- `/courts` — выбор типа суда, ссылки и поиск.
- `/courts/moscow` — алфавитные группы, поиск, карточки контактов.
- `/courts/moscow/registry/shcherbinskiy/info/judges` — длинный список официально опубликованных ФИО и дат.
- `/courts/moscow/registry/nikulinskiy/info/cases` — длинный текст, статус апелляции, источники.
- `/courts/moscow/judges` — фильтры и карточки дел.
- `/courts/moscow/registry/tushinskiy/info/filing` — пошаговые формы.
- `/courts/constitutional` и `/courts/constitutional/complaint` при наличии этих маршрутов — проверка больших юридических инструкций.

Контроль: заголовки не обрезаются, строки не тянутся на всю ширину монитора, нельзя случайно пропустить подписи источников, элементы нажимаются с клавиатуры, на телефоне нет нежелательной горизонтальной прокрутки страницы, а таблицы прокручиваются только внутри контейнера.

**Релиз:** после успешных CI + Moscow QA выполнить ручной Deploy `sudy-web` в Coolify по действующему процессу. Проверка UI не запускает Deploy и не обновляет DNS/Neon.
