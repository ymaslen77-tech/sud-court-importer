# Локальная сверка двух официальных реестров (только диагностика)

Этот инструмент отделяет «894/1000 записей апелляционного реестра прошли
проверку формата» от настоящего сопоставления первой инстанции с апелляцией.

Команда читает **только первые** 30 000 записей гражданских дел и первые
3 000 записей апелляции; все личные данные остаются в оперативной памяти
VPS, в выводе — только суммарные количества:

```bash
cd /srv/sudy-bulk-work
data/import/.moscow-venv/bin/python -m unittest discover -s importer/tests -p 'test_moscow_link_probe.py' -v
data/import/.moscow-venv/bin/python importer/moscow_link_probe.py --first-limit 30000 --appeal-limit 3000
```

Проверяются ключи УИД + номер нижестоящего дела, единственность подходящей
записи и согласованность судьи по уже имеющемуся официальному справочнику.
`technical_correspondence` — **только кандидат на связь записей**;
не полная юридическая приёмка, не подтверждение текста судебного акта,
не подтверждение апелляционного результата.

Отсутствие совпадения в **начальных частях** двух реестров не означает,
что судебное дело не существует. Для полноты понадобится отдельная
дисковая индексная сверка полного набора с проверкой конфликта по УИД,
номеру и суду. Импортёр, генераторы документов и frontend не изменены.
Данные не публикуются, не передаются в GitHub. Запуск Deploy запрещён.
