# Московские суды — единый поиск дел, этап 12.11.2026

## Для посетителей

- Новый адрес: `/courts/moscow/cases`; переходы из каталога Москвы, страницы судей и тематической страницы конкретного суда.
- Поиск по номеру производства, названию суда, имени судьи и категории.
- Фильтры: 35 районных судов, вид производства, категория и наличие результата в реестре.
- Каждая запись указывает первоисточник, дату просмотра и пределы подтверждения.
- При наличии двух согласующихся официальных реестров отражается **только регистрация** апелляционного материала; результат пересмотра не предполагается.
- Весь путь проходит через содержательные внутренние страницы; официальный первоисточник можно открыть сразу.

## Проверяемые границы данных

- Используются только ранее подготовленные публичные `moscow-judge-case-evidence.json` и `moscow-judge-bulk-cases.json`.
- На дату внедрения в них **27 + 0** записей; это локальная подборка, не полный архив всех дел Москвы.
- Набор `moscow-judge-crosschecked-cases.json` содержит **2** пары официальных записей первой и апелляционной инстанций; ни одна не подтверждает результат апелляции.
- `moscow-judge-reviewed-decisions.json` по-прежнему пуст: **0** прочитанных и утверждённых полных судебных решений.
- Не публикуются данные сторон, не создаются судебные мотивировки, нормативные выводы, рейтинги судей или оценка вероятности исхода дела.
- Для новых страниц остаётся `noindex` до редакционной юридической проверки. Прежние правила ссылок на первоисточники и ручного выпуска не меняются.

## Приёмка

1. GitHub Actions: общий `CI` и `Moscow GitHub-only data and website checks` на актуальном SHA.
2. Автоматический тест `test_moscow_case_index.py` проверяет, что все публичные записи привязаны к одному из 35 районных судов, ссылки находятся в официальном домене, нет полных текстов и данных сторон.
3. После ручного Deploy проверить на телефоне и ПК: `/courts/moscow`, `/courts/moscow/cases`, `/courts/moscow/judges`, `/courts/moscow/registry/nikulinskiy/info/cases`.
4. Для завершающей редакционной готовности всего раздела по-прежнему нужны свежие официальные списки для восьми судов и фактически прочитанные/одобренные тексты разрешённых к публикации решений.
