# Москва — единый исследовательский маршрут и подтвержденные практические контакты

Дата разработки 09.11.2026. Охват: **35** канонических карточек
районных судов Москвы (12 прежних подробных досье и 23 индивидуальных
карточки справочника). Московский городской суд ведётся отдельно.

## Что добавлено

1. Во все 35 карточек встроен единый внутренний навигатор: московский каталог,
   подсудность, поиск судьи/категории дел, индивидуальное досье судьи,
   обжалование и юридические сервисы. Это рекомендации, **не обязательная
   цепочка переходов**.
2. В карточке отображаются имеющиеся в проекте ФИО из официальных
   публикаций и небольшая выборка реестровых судебных записей. Это
   не подтверждённый текущий штат, не полный список дел, не рейтинг,
   не прочитанные мотивировочные части решений.
3. Для 8 районных судов добавлены индивидуальные справочные сведения из
   официальных страниц `/help/hours`: телефоны для маломобильных посетителей
   и антикоррупционные телефоны. Для части дополнительно — конкретные
   часы подразделений и ориентиры проезда. Сведения датированы; статус
   текущей доступности не подтверждён.
4. Официальные ссылки доступны без искусственного порога в пять
   переходов (сверка судебного факта должна оставаться доступной).
   Отдельные источники убраны в раскрывающиеся подробности, чтобы
   основная навигация оставалась внутренней.

## Правило юридической приёмки

- Автоматическое подтверждение распространяется только на **конкретное
  утверждение** при совпадении нормализованных полей и документов из
  независимых официальных публикаций с датами; одно лишь отсутствие
  противоречия НЕ равно двойной проверке.
- При расхождении сохранять обе версии в служебной проверке,
  публиковать официальный первичный источник, если его юридическая
  сила и применимость однозначны. Если конфликтуют два официальных
  сообщения — не выбирать произвольно, оставлять `needs_review`.
- Для судей: исторические списки не доказывают действующие полномочия.
  Для решений: реестровый исход не доказывает мотивировку.
- Участники дел, закрытые категории, детали персональных обращений
  в публичные карточки не добавляются.

## Завершение индивидуального справочного покрытия 35/35 (09.11.2026)

Добавлены сведения для оставшихся **14 районных судов Москвы**:
Бабушкинского, Басманного, Зеленоградского, Кунцевского, Люблинского,
Мещанского, Никулинского, Преображенского, Пресненского, Солнцевского,
Троицкого, Хамовнического, Черёмушкинского и Щербинского.

Теперь в каждой из 35 карточек предусмотрен индивидуальный блок из
официально опубликованной контактной страницы (не обязательно полный
контакт каждого подразделения). Указаны только доступные по источнику
телефоны, часы подразделений и детали проезда; отсутствующие значения
остаются `null`. Индивидуальные страницы могут быть историческими.
Технический охват 35/35 **не означает**, что все реквизиты подтверждены
действующими на момент посещения.

Особые случаи, которые нельзя упрощать:
- Басманный суд: из-за ремонта работа подразделений распределена по
  нескольким адресам. Один универсальный адрес для всех заседаний
  недостоверен.
- Черёмушкинский суд: временный адрес на Севастопольском проспекте и
  отдельный почтовый адрес на улице Кржижановского — разные реквизиты;
  в других официальных версиях встречается прежнее размещение.
- Пресненский суд: один телефон указан сразу для двух специальных
  задач; нужно уточнить назначение линии.
- Бабушкинский и Преображенский суды: расписание приёма и отдельное
  указание об отсутствии личного приёма судьями требуют корректного
  разграничения «аппарат суда» / «судья».
- Щербинский и Зеленоградский: часть справочных данных опубликована
  на исторических страницах `/hours`; транспортные маршруты не
  считаются проверенными в режиме реального времени.

Источник для каждого суда закреплён в
`apps/web/app/data/moscow-district-practical-facts.json` посредством
`sourceUrl`; `sourceUpdatedOn` указывается только там, где удалось
подтвердить дату из самой официальной публикации.

Правило проектирования пользовательского маршрута:
показываем максимально полную полезную информацию на собственной
странице, дополняем внутренними переходами к судье, делу, подсудности,
порядку подачи, госпошлине и обжалованию. При этом нельзя намеренно
блокировать прямую проверку официального первоисточника до пятой
страницы: ссылка должна быть доступна у соответствующего факта,
хотя может находиться в раскрывающемся блоке «Первоисточник».
Не копировать необезличенные материалы дел и не выдавать отсутствие
разночтений за независимую правовую приёмку.

Вопросы судов **Московской области** ведутся отдельно от 35 районных
судов **города Москвы**. Не переносить эту статистику на всю область.
