# Москва — единый исследовательский маршрут и подтвержденные практические контакты

Дата разработки 09.11.2026. Охват: **35** канонических карточек
районных судов Москвы (12 прежних подробных досье и 23 индивидуальных
карточки справочника). Московский городской суд ведётся отдельно.

## Что добавлено

1. Во все 35 карточек встроен единый внутренний навигатор: московский каталог,
   подсудность, поиск судьи/категории дел, индивидуальное досье судьи,
   обжалование и юридические сервисы. Это рекомендации, **не обязательная
   цепочка переходов**.
2. В карточке отображаются имеющиеся в проекте ФИО из официальных
   публикаций и небольшая выборка реестровых судебных записей. Это
   не подтверждённый текущий штат, не полный список дел, не рейтинг,
   не прочитанные мотивировочные части решений.
3. Для 8 районных судов добавлены индивидуальные справочные сведения из
   официальных страниц `/help/hours`: телефоны для маломобильных посетителей
   и антикоррупционные телефоны. Для части дополнительно — конкретные
   часы подразделений и ориентиры проезда. Сведения датированы; статус
   текущей доступности не подтверждён.
4. Официальные ссылки доступны без искусственного порога в пять
   переходов (сверка судебного факта должна оставаться доступной).
   Отдельные источники убраны в раскрывающиеся подробности, чтобы
   основная навигация оставалась внутренней.

## Правило юридической приёмки

- Автоматическое подтверждение распространяется только на **конкретное
  утверждение** при совпадении нормализованных полей и документов из
  независимых официальных публикаций с датами; одно лишь отсутствие
  противоречия НЕ равно двойной проверке.
- При расхождении сохранять обе версии в служебной проверке,
  публиковать официальный первичный источник, если его юридическая
  сила и применимость однозначны. Если конфликтуют два официальных
  сообщения — не выбирать произвольно, оставлять `needs_review`.
- Для судей: исторические списки не доказывают действующие полномочия.
  Для решений: реестровый исход не доказывает мотивировку.
- Участники дел, закрытые категории, детали персональных обращений
  в публичные карточки не добавляются.
