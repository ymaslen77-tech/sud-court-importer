# Проверка большого ZIP без повторной загрузки

При получении первого гражданского набора портал ответил `HTTP 200`,
`Content-Type: application/zip`, `Content-Length: 667506029`.
Распаковка остановилась на безопасном лимите 2 ГиБ:
`Uncompressed ZIP member exceeds configured cap`. Данные не опубликованы.

После ознакомления с условиями использования на официальном портале:

```bash
cd /srv/sudy-bulk-work
python3 importer/moscow_open_data_zip_probe.py --ack-source-terms
```

Команда читает по HTTPS только ZIP central directory и печатает
`uncompressedJsonBytes` и размер распакованного JSON в ГиБ для
двух гражданских наборов. Запросы `Range` должны возвращать HTTP 206.
Если сервер их игнорирует, команда откажет, не скачивая полный файл.
Исходные дела, ФИО сторон и тексты решений не извлекаются.

После просмотра результата выставить `--max-file-mib` больше
`uncompressedJsonBytes / 1048576`, с достаточным запасом для диска.
Учитывать дополнительное место на исходный ZIP, временный JSON и
другие уже скачанные файлы. Не устанавливать максимальное значение
вслепую.

Ни скрипт, ни тесты не запускают импорт, `git push` или Deploy.
