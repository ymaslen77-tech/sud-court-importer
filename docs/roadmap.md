# План развития

## MVP-1 — основа
- Монорепозиторий, Next.js, NestJS, PostgreSQL/PostGIS, CI.
- Реестр регионов, судов, судей, источников и истории изменений.
- Только проверенные карточки и SEO-адреса.

## MVP-2 — данные
- Проверяемый импорт открытых московских данных, staging и ручное утверждение.
- Контакты, судьи, история назначений, административный интерфейс.
- API с пагинацией и ограничением нагрузки.

## MVP-3 — сервисы
- Проверяемые нормативные границы подсудности, поиск по адресам.
- Законодательство, судебная практика, полнотекстовый поиск.
- Юридические калькуляторы и документы как отдельные модули.

Не создавать автоматически массовые малоценные SEO-страницы.
