# Анализ изменений телефонов и e-mail на официальной странице суда

## Статус

Реализован **офлайновый анализатор** сохранённых официальных HTML-страниц
`importer/official_contact_html.py`. Он не скачивает сайты, не запускает
периодический сбор, не меняет публичные карточки и не связывает телефон с
конкретным должностным лицом без дополнительной проверки.

Этот этап уменьшает ручную работу после получения *разрешённых* снимков.
Он не заменяет проверку условий обращения к источнику и редакционное
подтверждение конкретного телефонного номера.

## Команды

Сохранить полученные разрешённым способом снимки в
`data/import/hours-old.html` и `data/import/hours-new.html` (вне Git).
Пример команды просмотра извлечённых контактов:

```powershell
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/official_contact_html.py inspect /input/hours-new.html --source-url https://mos-gorsud.ru/rs/lefortovskij/help/hours
```

Пример сравнения:

```powershell
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/official_contact_html.py compare /input/hours-old.html /input/hours-new.html --source-url https://mos-gorsud.ru/rs/lefortovskij/help/hours
```

URL должен соответствовать официальной странице вида
`/rs/<court>/help/hours`; исходные файлы передаются вручную.
Смена написания номера `+7` ↔ `8` без изменения цифр не создаёт события.

Сигналы:
- `newly_observed`: номер/e-mail появился в новом HTML;
- `not_observed_in_new_snapshot`: значение отсутствует в новом HTML,
  **не означает, что номер отключён или контакты изменены**.

Сохранены SHA-256 обоих файлов и фрагменты видимого текста вокруг
контакта для дальнейшего сверения с официальной страницей.
Скрипты, стили и скрытые технические блоки игнорируются.
Не извлекаются автоматически ФИО судей, факт назначения, часы работы
конкретного отдела и юридическая подсудность.

## Критерии готовности

1. Оба HTML-снимка легально и независимо получены одним оператором
   по той же официальной ссылке.
2. Реальный формат страницы проверен по каждой категории судебного сайта.
3. Сигналы сверены с первоисточником; неоднозначности отклонены.
4. При необходимости поле переносится в существующий
   `profile.py propose` только для уже verified-суда, а затем
   `profile.py approve` после независимого подтверждения.
5. Для круглосуточной эксплуатации потребуется отдельный доступный
   сервер, разрешённая периодическая загрузка и сохранение официальных
   снимков; этот этап таких операций не делает.

В тестах используются вымышленные номера и документы. Никакие
публичные сведения не публикуются.
