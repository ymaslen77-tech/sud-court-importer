# Приёмка проекта «Суды России» — критерии и фактический статус

Дата исходной инвентаризации: 13 октября 2026 года. Обновление разработки: 14 октября 2026 года.

Нельзя приравнивать успешный CI к достоверному общероссийскому каталогу. Каждый этап закрывается отдельно: **код и тесты**, **доказательства источника**, **фактические данные**, **публикация и эксплуатация**.

| Этап | Объективный критерий закрытия | Текущий результат | Статус |
|---|---|---|---|
| 1. Аудит кода и БД | Репозиторий/миграции согласованы, CI зелёный, есть rollback/backup | Next/Nest/Python/Docker CI, скрипт безопасного локального обновления, миграции 001–008 | Код подготовлен; последняя CI-проверка — отдельно по run |
| 2. Источники и права | Для каждого реестра есть официальный документированный экспорт, условия машинного доступа и разрешённые лимиты | Проверены страницы ГАС «Правосудие», arbitr.ru, mos-gorsud.ru; регулярный API/лицензия источников ещё не подтверждены | **Блокер** |
| 3. | 5. ## Три разных счётчика

- **Предварительные записи о судебных органах и участках:** 206 (121 + 75 + 10), взяты из опубликованных официальных списков. Не складывать без понимания разновидностей объекта и возможных дублей.
- **Предварительные кадровые наблюдения:** 11 ФИО и реквизитов указов из одной официальной страницы; не считать действующими назначениями.
- **Новые полностью подтверждённые публичные карточки из этих выборок:** 0 до независимой редакционной проверки и фактического допуска.

CI использует также **синтетические** записи и фрагмент четырёх реальных судов из проверочной выборки, но они не меняют публичный счётчик.

## Условия перехода на следующий этап

1. Для массового импорта получить именно разрешённый официальный файл/канал, доказанную схему, дату получения, право регулярного использования, ограничения запросов. Без этого включать сетевой робот нельзя.
2. Для каждого публичного суда подтвердить идентификатор, актуальное название и тип, адрес, сайт, источник, дату сверки; изменения ревьюить по полям.
3. Для каждого назначения судьи подтвердить личность, должность, дату/реквизиты акта и актуальность. Отсутствие ФИО в одном HTML-снимке не доказывает увольнение.
4. Для координат и фото — отдельные доказательства адресной привязки и лицензии; пустые места лучше вымышленных данных.
5. Для практики — законный способ доступа к тексту судебного акта, соблюдение ограничений на персональные данные, связь с судом и судьёй только при надёжной идентификации.
6. Перед публичным запуском: URL HTTPS, защита БД, тест восстановления бэкапа, непрерывный мониторинг, редакторский доступ, приёмочные тесты и отчёт `importer/readiness.py`. `nationwide_complete` не должен считаться true без полного источникового охвата.

## Команды контроля фактического состояния

```powershell
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/coverage.py
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/readiness.py
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/registry_diff.py pending
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/watch.py pending
```

Если сведения отсутствуют или дата устарела, честно выводить «нужна проверка», а не подтверждать публикацию. Расширение по всем субъектам — отдельная доказательная работа, которую нельзя подменить количеством сгенерированных страниц.

  миграция `011_court_contact_review.sql`, закрытая очередь

  `watch_id` существующего проверенного суда; имя, роль номера и

- Доступен [проверочный пакет из пяти московских районных судов]
  (./moscow-five-courts-source-verification-2026-10-14.md).
  Одна конфликтная пара адресных сведений Кунцевского суда требует
  дополнительной ручной проверки до публикации.
- Пакет из пяти записей **не добавляется к 206 исходным объектам**:
  это отдельная исследовательская очередь, а не новые подтверждённые суды.
  Из этого исследовательского пакета в публичную БД автоматически
  опубликовано **0**.
- Обнаруженные сигналы не считаются доказательством изменения поля,
  особенно когда оно исчезло с одной HTML-страницы.
- **Условия реального массового получения данных, юридическая редакционная
  проверка источников, production-хост/бэкапы, геоданные и фото
  остаются незавершёнными.** Успешный CI подтверждает корректность
  синтетического пилота, а не общероссийскую актуальность.
