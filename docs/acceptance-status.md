## Три разных счётчика

- **Предварительные записи о судебных органах и участках:** 206 (121 + 75 + 10), взяты из опубликованных официальных списков. Не складывать без понимания разновидностей объекта и возможных дублей.
- **Предварительные кадровые наблюдения:** 11 ФИО и реквизитов указов из одной официальной страницы; не считать действующими назначениями.
- **Новые полностью подтверждённые публичные карточки из этих выборок:** 0 до независимой редакционной проверки и фактического допуска.

CI использует также **синтетические** записи и фрагмент четырёх реальных судов из проверочной выборки, но они не меняют публичный счётчик.

## Условия перехода на следующий этап

1. Для массового импорта получить именно разрешённый официальный файл/канал, доказанную схему, дату получения, право регулярного использования, ограничения запросов. Без этого включать сетевой робот нельзя.
2. Для каждого публичного суда подтвердить идентификатор, актуальное название и тип, адрес, сайт, источник, дату сверки; изменения ревьюить по полям.
3. Для каждого назначения судьи подтвердить личность, должность, дату/реквизиты акта и актуальность. Отсутствие ФИО в одном HTML-снимке не доказывает увольнение.
4. Для координат и фото — отдельные доказательства адресной привязки и лицензии; пустые места лучше вымышленных данных.
5. Для практики — законный способ доступа к тексту судебного акта, соблюдение ограничений на персональные данные, связь с судом и судьёй только при надёжной идентификации.
6. Перед публичным запуском: URL HTTPS, защита БД, тест восстановления бэкапа, непрерывный мониторинг, редакторский доступ, приёмочные тесты и отчёт `importer/readiness.py`. `nationwide_complete` не должен считаться true без полного источникового охвата.

```powershell
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/coverage.py
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/readiness.py
```
