# Offline inbox v2 — контроль целостности

Дата: 14 октября 2026 года. Этот механизм НЕ скачивает судейские сайты и НЕ публикует суды.

Новые производственные манифесты должны иметь формат `moscow-contacts-v2` либо `sudrf-federal-list-v2`, с дополнительным обязательным полем `snapshot_sha256`: 64 шестнадцатеричных символа в нижнем регистре. Хеш рассчитывается по исходным байтам сохранённого файла, а не по нормализованному JSON.

PowerShell 7, из папки репозитория:

```powershell
(Get-FileHash .\data\import\inbox\contacts.json -Algorithm SHA256).Hash.ToLowerInvariant()
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/inbox.py check
docker compose -f compose.local.yaml run --rm --entrypoint python importer /work/importer/inbox.py stage
```

Пример полей v2: `format`, `file`, `dataset_url` (либо `source_url`, `region`, `region_name`), `captured_on`, `reviewer`, `reuse_rights_confirmed`, `snapshot_sha256`.

Повторное использование данных и допустимость получения должны быть проверены оператором по реальным условиям источника; поле подтверждения не заменяет разрешение. `v1` временно поддерживается для старых пилотных файлов.

На стадии предварительной проверки каждый файл читается и разбирается один раз. Если один из файлов недействителен, `stage` блокирует ВСЕ файлы текущего пакета до обращения к staging-импортёрам и сохраняет отчёт о сбое. При успешной предварительной проверке пакет направляется только в закрытый staging; факты по каждой карточке проходят отдельную редакционную проверку.

Предел — 100 манифестов и 50 МБ снимков в одном пакете. Не допускаются символьные ссылки, выход из inbox, повторное использование одного файла или несколько снимков одного источника за одну дату в одном пакете.

**Граница гарантии:** блокировка действует до начала staging. Сбой во время дальнейших записей БД может оставить уже обработанные закрытые пакеты; распределённой транзакции на все источники нет. Публичная таблица судов автоматически не меняется.

Новые реальные карточки: **0**. Полнота официальных выгрузок и условия регулярного получения данных всё ещё требуют внешней проверки.
