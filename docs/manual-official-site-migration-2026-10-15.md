# Проверка индивидуальных официальных URL перед публикацией (15.10.2026)

## Исправленный технический барьер
Исходные региональные перечни могут хранить старые HTTP-адреса вида `barabinsky.nsk.sudrf.ru`. Отдельная актуальная HTTPS-страница имеет иной хост `barabinsky--nsk.sudrf.ru`. Прежний механизм требовал точного совпадения hostname/path и блокировал ручной выпуск даже при проверенной миграции.

Добавлен `importer/verification.py` и подключён к команде индивидуальной приёмки `importer/cli.py approve`. Импортёр:
- сохраняет URL исходного снимка без изменений;
- требует отдельный текущий корневой HTTPS URL и URL индивидуального доказательства на том же официальном хосте;
- при изменении имени сайта/пути требует `--attest-site-migration` — **только после независимой проверки идентичности суда и кода ответственным редактором**;
- на общем московском хосте требует доказательство именно внутри пути данного суда;
- записывает новый официальный первоисточник и индивидуальную дату сверки в `sources`, аттестованные факты связывает с этой страницей;
- отдельно сохраняет событие изменения URL, не переписывая `court_import_rows`;
- по-прежнему требует `--attest-current` и `--attest-reuse-rights`, не создаёт суды автоматически.

Пример **после реальной ручной проверки** (не запускать только на основании исследовательской карточки):

```bash
python importer/cli.py approve --batch 1 --code 54RS0012 \
  --reviewer "ФИО проверяющего" --checked-on 2026-10-15 \
  --verification-url "https://barabinsky--nsk.sudrf.ru/modules.php?name=info_court&rid=2" \
  --current-site-url "https://barabinsky--nsk.sudrf.ru/" \
  --attest-site-migration --attest-current --attest-reuse-rights
```

`--batch 1` — исключительно иллюстрация: настоящий `batch_id` берётся из БД по конкретному `external_code` и исходной записи, а не угадывается.

## Пределы исправления
Сама проверка принадлежности домена `sudrf.ru` не подтверждает, что на нём расположен именно этот суд. Авторизация ручного решения, сверка идентичности, адреса, телефонов, процессуальной компетенции и действующих условий использования обязательны. Сведения о судьях, территориальных границах и банковских реквизитах не приобретают статус подтверждённых автоматически.

До выпуска первого суда: выполнить тесты, независимую полевую сверку и редакционную аттестацию; только затем проверить Neon, API, SEO и Vercel. Без таких действий все 76+197 записей остаются в staging.
