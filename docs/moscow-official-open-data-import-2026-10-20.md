# Импорт настоящих дел с портала открытых данных судов Москвы (20.10.2026)

Официальный источник: https://data.mos-gorsud.ru/opendata — 40 наборов данных, включая гражданские, административные и уголовные дела, исход дела и ссылки на судебные акты.

## Состояние
Веб-каталог содержит 33 существующие карточки результатов и 0 проверенных полнотекстовых судебных актов. Цель «50 полных решений на категорию» пока **не достигнута**.

Скрипт `importer/stage_moscow_open_data.py` **не скачивает**, не публикует, не импортирует в Neon и не переносит информацию об участниках. Нужен локальный исходный JSON/NDJSON, скачанный с официального портала при соблюдении актуальных условий использования. Крупные JSON (>20 MB) считываются потоково при наличии `ijson`.

Пример:
```bash
python -m pip install ijson
python importer/stage_moscow_open_data.py --input /private/original-moscow-cases.json --output /private/stage-moscow-cases.json
```

### Редакторская приёмка
1. Установить, что поля фактической выгрузки соответствуют объявленной схеме. Несовпадение формата не обходить молчаливо.
2. Сверить номер, суд, категорию, результат и источник по индивидуальной карточке дела.
3. Проверить публикационную допустимость по статье 15 ФЗ № 262, обезличивание, наличие оригинального опубликованного акта и условия использования портала.
4. Дедуплицировать по суду, номеру и источнику; отделить судебные акты от записей о процессуальных действиях.
5. Только затем перевести отдельные записи в `approved_for_display`; тексты полноценных актов публиковать только после самостоятельной проверки оригинала.
6. Подсчитывать 50 **полных и одобренных документов**, а не 50 JSON-записей. Если правовая категория исключена из публикации, норматив не применяется.

Отдельный импорт адресной подсудности нужен из точного официального реестра по улицам/домам/корпусам/строениям. Открытые данные о судебных делах не заменяют его.
