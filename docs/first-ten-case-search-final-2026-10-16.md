# Итоговая приёмка: локальное содержание 10 судебных карточек и поиск по делам

Дата: 16.10.2026. Ветка реализации: `feat/003-court-case-search`.

## Включено в публичные карточки

1. Проверенные ранее справочные идентификация, адреса и контакты; источники и дата исследования; предупреждения об ограниченной актуальности.
2. Расширенные сведения об отдельных подразделениях и зданиях там, где они есть в официальных публикациях.
3. Локальное содержание: порядок подачи и комплект документов, электронная подача, правила электронной подписи, пошлина по НК РФ (без непроверенных платёжных реквизитов), обобщённая компетенция.
4. Интерактивные Яндекс Карты. Координаты четырёх адресов предварительные, остальные карты используют адресный поиск; точный вход не утверждается.
5. Встраиваемое расписание **только за календарное сегодня** в местном часовом поясе суда; отсутствие ответа не выдаётся за отсутствие заседаний.
6. **Поиск дела по номеру на странице суда**: фильтрация лишь фактически полученного списка заседаний на сегодня. При совпадении отображаются номер, время, зал, судья и **точная официальная ссылка на карточку дела** — если сам источник её предоставил. Из нашего проекта ни документы, ни сведения о сторонах не копируются.
7. Для **всех дел вне сегодняшнего списка** — отдельная явная ссылка на официальную форму поиска соответствующего суда (`modules.php?name=sud_delo&srv_num=1&name_op=sf`). Это переход к форме, **не автоматический поиск по всем архивным делам**. При необходимости номер вводится пользователем ещё раз.

## Ограничение индекса

Полный исторический каталог дел пока не хранится у нас в БД. На сегодня подтверждённых действующих записей `court_case_references` для этих десяти судов нет. Поэтому нельзя заявлять, что внутри портала можно получить полный поиск всех дел. Полный охват возможен только после открытия официально разрешённого машинного канала/API либо редакционного наполнения собственного индекса с корректными ссылками, датой и источником. Пока официальный поиск доступен через ссылку.

Модуль сегодня запрашивает ограниченный публичный список с `H_date`, использует `Asia/Omsk`/`Asia/Novosibirsk`, одночасовой кеш и валидирует дату. При отказе доступа не показывает архивные данные. Проверка 16.10.2026 показала тайм-аут официальных сайтов Омского и Барабинского судов. Это внешнее ограничение; виджет при отказе должен показывать понятное сообщение.

## Критерии релиза

- Тесты импортёра и отдельные тесты поиска (не допускать фиктивных совпадений).
- Сборка Next.js / NestJS, безопасность, локальные smoke — GitHub Actions.
- Vercel `READY` точно на опубликованном SHA.
- Внешний HTTP smoke десяти карточек, наличие поискового поля и корректного маршрута к официальной форме.
- Не изменять `court_import_rows`, `courts.status` и `court_public_references` без необходимости.

## Сведения, которые не следует объявлять закрытыми

- Надёжная машинная доставка текущих списков из ГАС «Правосудие» без отдельного канала.
- Точная геометрия входов в шесть зданий без подтверждения.
- Персональные назначения, банковские реквизиты и детальные адресные границы, пока не проверены отдельными официальными актами.
- Полноиндексный поиск по всем делам за все годы.
