# Инвентаризация 40 наборов открытых данных судов Москвы

Основание: предоставленный пользователем экспорт `meta.json` с 40 идентификаторами
и URL паспортов. В `importer/moscow_open_data_registry.py` они учтены все.

| Тип | Количество | Назначение |
|---|---:|---|
| first | 8 | Материалы и дела первой инстанции |
| appeal | 11 | Апелляция и пересмотр |
| index | 5 | Общие перечни для сверки |
| context | 9 | Контакты, первичные документы, заседания, статистика |
| excluded | 7 | Доходы/демография/внепроцессуальные обращения; не импортировать в карточки |

Всего 33 потенциально полезных набора. Они **не являются 33 проверенными
источниками данных** до загрузки и проверки схем. Доступность исторического
endpoint `/latest/data/json/` на ноябрь 2026 не подтверждена. Паспорта
не являются сами по себе ссылками на файлы судебных дел.

## Подготовка на VPS

Рабочая папка проекта: `/srv/sudy-bulk-work`, ветка
`infra/coolify-russian-vps`. Сначала выполнить `git pull --ff-only`.
Весь исходный JSON остаётся ВНЕ Git и Docker, в
`/srv/sudy-private/moscow-open-data/`.

Без доступа к интернету и изменения данных:

```bash
python3 importer/moscow_open_data_acquire.py plan --scope eligible
```

Перед сетью открыть https://data.mos-gorsud.ru/ и проверить **условия
повторного использования**. Если условия не установлены или запрещают
переработку, НЕ применять флаг подтверждения.

Пробная загрузка пары для существующего гражданского импортёра:

```bash
python3 importer/moscow_open_data_acquire.py fetch --scope eligible \
  --only 1577116594824-casesgroupfirstcivilhxvgb 1577117744056-casesgroupmgsappealcivilwtxga \
  --ack-source-terms
```

Далее **только локальная** проверка имён полей:

```bash
python3 importer/moscow_open_data_acquire.py inspect --scope eligible \
  --only 1577116594824-casesgroupfirstcivilhxvgb 1577117744056-casesgroupmgsappealcivilwtxga
```

Отчёт: `/srv/sudy-private/moscow-open-data/acquisition-report.json`.
Для больших файлов, чтобы извлечь первую запись потоково, потребуется
`ijson` в среде Python; его отсутствие не выдаётся за проверку схемы.

Для загрузки остальных применимых наборов после контроля диска и
прав доступа доступен `fetch --scope eligible --ack-source-terms`.
Параметры `--max-file-mib` (по умолчанию 2048) и
`--max-total-gib` (по умолчанию 12) защищают от переполнения VPS;
при отказе/редиректе/HTML загрузка останавливается.

**Публикация не выполняется.** Только гражданская пара может быть
передана существующему `scripts/moscow-bulk-release.sh`, сначала
без `--apply`. Остальным 31 возможным набору нужна собственная карта
полей и карантин несовпадений, а материалам закрытых дел нельзя
приписывать мотивировку. Не копировать ФИО сторон и необезличенные
судебные акты в Git. Никакого Coolify Redeploy.

Проверка:
```bash
python3 -m unittest discover -s importer/tests -p 'test_moscow_open_data_acquire.py' -v
```

## Проверено по HTTP-заголовкам на VPS 04.11.2026

- Гражданские дела первой инстанции: HTTP 200, `application/zip`,
  `content-length: 667506029`, вложение `data.json.zip`.
- Гражданские апелляционные дела: HTTP 200, `application/zip`,
  `content-length: 185779205`, вложение `data.json.zip`.

Это **не** означает, что содержимое архивов уже проверено.
Загрузчик умеет распаковывать GZIP и ZIP в закрытом каталоге; ZIP должен
содержать ровно один JSON, иначе операция останавливается. Распаковка не
привязана к исходному имени из архива и ограничена размером. На VPS
необходимо иметь достаточно свободного места для исходного архива И JSON.
Проверка `df -h /srv` до загрузки обязательна.

Изменения только в загрузчике; `--apply`, `--push` и Deploy НЕ выполняются.
Для фактического скачивания обязательно отдельно подтвердить условия
использования открытых данных. Не передавайте персональные данные сторон.
