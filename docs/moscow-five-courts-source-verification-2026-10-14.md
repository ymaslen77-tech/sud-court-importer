## Правила качества

- Не путать единую справочную линию `+7 (499) 530-08-08` с прямым
  телефоном экспедиции или приёмной; явно сохранять роль номера.
- Официальный e-mail **не предназначен для направления исковых
  заявлений и жалоб**, если об этом предупреждает сама страница.
  Должна быть отдельная инструкция о подаче процессуальных документов.
- Сведения о судьях и руководителях из кратких контактов **не являются**
  достаточным доказательством действующего назначения.
- Сведения ниже являются **проверочными заданиями** для редактора, а не
  одобренными карточками. Не генерировать классификационные коды судов.
- После фактической проверки назначить код из соответствующего официального
  реестра и выполнить контролируемое `stage` → `approve`, сохраняя
  источники для каждого поля. При конфликте адреса оставить поле
  непубликуемым до разрешения расхождения.
- Общероссийское покрытие, разрешённое массовое получение данных, фото
  фасадов, координаты и производственный мониторинг из этих пяти
  наблюдений не следуют.
