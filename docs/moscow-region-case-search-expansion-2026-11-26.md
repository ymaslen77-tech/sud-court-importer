# Москва + Московская область: сквозной поиск судов и судебных дел — 26.11.2026

## Фактически существовавшие в проекте сведения

До этого этапа:
- **Москва:** 35 районных судов и Московский городской суд в общем официальном перечне, индивидуальные карточки и локальная подборка номеров судебных дел; отдельный фильтр `/courts/moscow/cases`.
- **Московская область:** уже **45 датированных справочных карточек** из [официального перечня Управления Судебного департамента](https://usd--mo.sudrf.ru/modules.php?name=sud), включая Московский областной суд. Карточки не равны заверенному реестру актуальных назначений/реквизитов.
- Общий `/search` прежде находил эти суды по названию и региону, но не выводил локальные судебные дела как отдельный тип совпадений; ссылки областных карточек часто вели только на главную суда.

## Новый пользовательский маршрут

`/courts/moscow-region/cases` (временно **noindex**):
- Единая панель с поиском по номеру, категории и названию суда, фильтрами по Москве / Московской области, конкретному суду и характеру подтверждённости результата.
- Список доступных судов берётся из действующих исходных каталогов: не дублирует вручную 35+45 карточек и не подменяет территориальную подсудность.
- Действующие записи московских дел `MOSCOW_JUDGE_CASE_EVIDENCE` используются без изменения, результаты первой инстанции показываются отдельно от пересмотра.
- Для областных судов использован датированный **индекс 4 апелляционных производств** без персональных данных участников; новых судебных исходов и мотивировок не добавлено.
- При выборе суда доступен переход в исходную карточку суда и, при фактической проверке формы делопроизводства, в официальный поиск. Для остальных областных судов — только оригинальный официальный сайт (с инструкцией открыть «Судебное делопроизводство»), без выдуманной прямой ссылки.
- Главный поиск `/search` теперь показывает подходящие локальные дела, а также направляет в объединённый каталог; суда без совпавших дел не исключаются из поиска по названиям.
- Прямые переходы добавлены из `/courts/moscow`, `/courts/moscow/cases`, `/courts/region-50`, областных карточек `/courts/reference/[slug]` и шапки.

## Границы публикации и работа, которая остаётся

1. **Текущий состав судей, законный статус и назначения:** для Московской области ещё не обогащены по всем 45 карточкам; для Москвы открыта issue #62 с шестью не извлечёнными полными историческими списками.
2. **Реестровые статусы:** сам факт включения в старый список заседаний не означает результат. Исход апелляций следует проверять по доступной карточке и подлинному акту, включая назначенное на 19.11.2026 заседание Мосгорсуда № 33-53951/2026 (карточка на ноябрь повторно не получена, итог неизвестен).
3. **Полные судебные решения:** 0 проверенных и разрешённых к публикации мотивированных текстов. Ни один текст дела из данного этапа не копировался.
4. **Территориальная подсудность:** по одному названию города, метро, району или адресу суда автоматически не определяется; точные домовые данные необходимо сверить отдельно.
5. **Актуальность:** телефон и адрес в официальном списке могли измениться с даты старой публикации. Наличие 45 карточек не равно 45 актуально проверенным справочникам.
6. **SEO:** новая поисковая страница `noindex` до принятия документов; данные областного суда доступны как исследовательские, не как удостоверенная профессиональная правовая консультация.
7. **Автоматический импорт:** не включён, нет обхода ограничений ГАС «Правосудие» и нет публикации необработанных персональных данных.
