# Суды России — правовой портал

Репозиторий для независимой разработки единого информационного портала судов Российской Федерации.

Архитектура, исходный код и инструкции появятся в отдельной ветке разработки. Информация о судах должна иметь проверяемый официальный источник; демонстрационные сведения не публикуются как реальные.
